## 3. What to do (priority order)

1. **`xlsx@0.18.5` (only AFFECTED runtime-adjacent dep).** Do not parse
   untrusted uploads with it. Prefer removing it (`scripts/geral-coverage.ts`
   is the only non-test importer) or vendoring SheetJS ≥0.20.2 from
   cdn.sheetjs.com. Prod XLSX export (`lib/export/xlsx/`, `lib/server/`)
   does not use it — confirm before deleting.
2. **`postgres:18-alpine` (done 2026-10-09).** Pinned + digest-locked; existing PG16 `pgdata` needs dump/restore (see `compose.yml`).
3. **`source-map-js@1.2.1`.** Build-time only, no action needed unless the
   build ingests untrusted sourcemaps; picks up fix automatically with the
   next Vite/postcss bump.
4. **Hygiene (no bulletin, reduces future blast radius):** prune the orphan
   `pdf-lib` lock entry; keep `denoland/deno` digest fresh; never expose
   `deno task dev` (`:5173`) beyond localhost; keep `-A` services (`app`,
   `poller`, `alerts`, `tools`) network-isolated except `db` + `:8000`.
